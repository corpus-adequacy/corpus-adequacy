overview

Non-claims

  • Two evidence classes, two denominators. They are never added together, and neither is a population estimate.
  • A declared set that kills every mutant shows its own mutants are distinguished. It does not show the rule set is complete. The independent column is one probe of that, not a proof.
  • Authorship names are recorded as written and are not authenticated.
  • Local contained evidence, not hosted containment proof. A survivor is bounded to this selection, corpus, projection, environment and host.
  • No evidence class proves rule completeness, corpus quality, implementation correctness, real-world prevalence, security, conformance, or author independence.
  • Each denominator is one declared selection and is not a population estimate.
  • This artifact defines one class only; no aggregate score or overall adequacy exists.
