# Code of Conduct

Corpus Adequacy adopts the [Contributor Covenant version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
as its Code of Conduct. It applies in this repository, its issues, pull requests
and Discussions, and whenever someone represents the project.

The Contributor Covenant text is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The sections
below provide the project-specific reporting route and handling limits that
accompany that standard.

## Reporting

Report a conduct concern privately by email to
**[roelschuurkes@gmail.com](mailto:roelschuurkes@gmail.com)**.

This address is for conduct concerns only. Report a security vulnerability
through the private route in [SECURITY.md](SECURITY.md). Neither route stands in
for the other. Do not put a conduct report in a public issue, pull request or
Discussion.

## Who reads a report

Roel Schuurkes is the only person who reads this address for the project. There
is no deputy or alternate recipient, and there is no independent appeal route
inside the project. If Roel is unavailable, handling may be delayed. The
project does not claim continuous coverage.

A report about Roel still reaches Roel. A reporter who needs a route outside
the project can use the reporting option on the relevant GitHub content or
account, or [GitHub's abuse-reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

## What happens after a report

Roel will assess a report when available and choose a proportionate response
under the Contributor Covenant's *Addressing and Repairing Harm* section. No
response or resolution time is promised.

Report details will be shared only as reasonably needed to understand the
concern, protect people, meet legal obligations, or take action. The project
will not publish a report without the reporter's consent unless required for
one of those purposes, but it cannot guarantee confidentiality.

## Limits

This policy does not by itself make the community safe. It does not establish a
backup recipient, uninterrupted handling, an enforcement service-level
agreement, or an independent review body.
